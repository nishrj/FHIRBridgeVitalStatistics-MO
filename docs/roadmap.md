# Roadmap

Current MVP includes synthetic fixed-width input, standalone Python/Jupyter
conversion, embedded CORE-aligned structure, VRDR/FHIR JSON Bundle output,
mapping documentation, successful Missouri synthetic CORE parser/import testing,
and CQL/NDJSON extensions.

Next steps:

1. Repeat CORE imports using freshly generated standalone output.
2. Run applicable VRDR profile validation.
3. Compare mapped source values with generated FHIR output.
4. Replace synthetic scaffolding as additional legitimate source fields are mapped.
5. Execute/refine the CQL prototype.
6. Test NDJSON output with larger synthetic volumes.
7. Prototype a configurable/low-code mapping interface for other registries.
