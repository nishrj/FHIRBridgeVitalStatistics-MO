# Planned Configurable UI

A Figma Make mockup was created to show a possible future FHIRBridge-MO
interface.

The concept includes Upload Source File, Define File Layout, Map Fields to FHIR,
Validate & Preview, and Export CORE-oriented FHIR. It also shows source metadata,
a field-layout designer, mappings, validation summary, FHIR preview, and
JSON/NDJSON/CQL-oriented output options.

**The Figma screen is a design concept only.** The working MVP is currently the
Python/Jupyter transformation pipeline.
